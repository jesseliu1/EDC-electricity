# 技术栈文档 (TECH_STACK)

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        前端 (Vue 3)                          │
│  Element Plus + ECharts + Tailwind CSS + Vue Router + Pinia │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     后端 (FastAPI)                           │
│          Pydantic + SQLAlchemy + httpx + APScheduler        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    数据层 (SQLite)                           │
│                L2 层：基线、任务单、设置                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   EDC API (外部)                             │
│              L0/L1 层：原始时序数据                           │
└─────────────────────────────────────────────────────────────┘
```

## 5. 禁止使用

以下包/技术**禁止**使用，除非经过明确批准：

| 类别 | 禁止项 | 原因 |
|------|--------|------|
| 前端框架 | React, Angular, Svelte | 项目已选定 Vue |
| UI 库 | Ant Design, Vuetify | 项目已选定 Element Plus |
| 状态管理 | Vuex, Redux | 项目已选定 Pinia |
| ORM | Django ORM, Tortoise | 项目已选定 SQLAlchemy |
| 数据库 | MySQL, PostgreSQL, MongoDB | MVP 使用 SQLite |
| 包管理 | npm, yarn, pip | 使用 pnpm + uv |

## 6. 版本锁定策略

- 使用 lockfile 锁定版本（pnpm-lock.yaml, uv.lock）
- 次版本更新需测试后合并
- 主版本更新需评审后决定
