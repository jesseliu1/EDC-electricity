# 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
ASNS AI老师傅智慧熔炼系统

### 1.2 产品定位
基于黄金基线的中频炉熔炼过程偏差监控与纠偏系统。帮助铸造厂实现：
- 生产过程标准化（黄金基线）
- 实时偏差监控（容许误差对比）
- 纠偏任务闭环（任务单管理）
- 生产报表自动化（日报周报）

说明：老师傅系统（基线系统）与日报系统为独立模块，可按模块拆分交付与销售。

### 1.3 目标用户
- **厂长/生产主管**：查看总览、审批任务单
- **工程师/老师傅**：设置基线、分析偏差、处理纠偏
- **操作员**：接收纠偏提示、执行操作

## 2. 功能范围

| 模块 | 功能 | 优先级 | 状态 |
|------|------|--------|------|
| **总览 Dashboard** | 当日炉数、平均偏差、实时曲线对比 | P0 | 待开发 |

| **偏差收件箱（简化版）** | 偏差列表、查看详情（不含分配） | P1 | 待开发 |
| **日报系统** | 自动生成日报、PDF导出 | P1 | 待开发 |

### 2.2 延后功能（不在 MVP 范围）

| 功能 | 原因 |
|------|------|
| AI 智能诊断 | 需要数据积累和模型训练 |
| 偏差收件箱（分配到人） | 需要用户权限系统 |
| 知识卡/RAG | 需要知识库建设 |
| 多台 EDC 支持 | MVP 先做单台 |
| 周报系统 | 日报完成后扩展 |

## 3. 功能详细说明

### 3.1 总览 Dashboard

**目的**：一眼了解当日生产状态

**展示内容**：
- 当日总炉数
- 平均偏差百分比
- 待处理纠偏任务数
- 黄金基线状态
- 实时曲线对比图（黄金基线 vs 当前生产）

**交互需求**：
- 曲线图可选择时间范围（5分钟/1小时/6小时/全天）
- 侧边栏可收起，图表可最大化
- 点击炉次可跳转详情

### 3.2 黄金基线库

**目的**：管理生产标准基线

**功能**：
- 基线列表（名称、创建时间、状态、版本）
- 新建基线向导：
  1. 选择候选炉次
  2. 预览曲线
  3. 设置容许误差
  4. 发布/保存草稿
- 基线版本管理
- 基线启用/停用

**数据结构**：
- 基线ID、名称、描述
- 关联炉次ID
- 功率曲线数据
- 电压曲线数据
- 温度数据
- 容许误差（%）
- 状态（草稿/已发布/已停用）
- 版本号

### 3.3 炉次浏览

**目的**：查看历史炉次及偏差情况

**功能**：
- 炉次列表（时间、编号、偏差状态）
- 炉次详情：
  - 曲线对比图（与黄金基线叠加）
  - 偏差区间标记（红色高亮）
  - 偏差百分比
- 生成纠偏任务入口

### 3.4 纠偏任务单

**目的**：管理偏差处理闭环

**功能**：
- 任务列表（状态筛选：待处理/处理中/已完成）
- 创建任务（从炉次详情页触发）
- 任务详情：
  - 关联炉次信息
  - 偏差曲线对比
  - 原因分析（文本填写）
  - 改善方法（文本填写）
  - 预防对策（文本填写）
- PDF 导出

### 3.5 日报系统

**目的**：自动生成生产日报

**内容**：
- 当日生产统计（总炉数、有效稼动时间）
- 偏差汇总（正常/异常比例）
- 纠偏任务汇总
- 关键指标趋势

**导出**：PDF 格式

### 3.6 系统设置

**配置项**：
- 默认容许误差（%）
- EDC 连接配置（API地址）
- 报表生成时间

### 3.7 偏差收件箱（简化版）

**目的**：集中查看偏差记录

**功能**：
- 偏差列表（时间、炉次、偏差百分比、状态）
- 查看偏差详情（跳转到炉次详情）
- 不包含人员分配与流程流转

## 4. 非功能需求

### 4.1 性能
- 曲线数据加载 < 2秒
- 支持 24 小时连续数据展示

### 4.2 兼容性
- 浏览器：Chrome 90+、Edge 90+
- 分辨率：1920x1080 优化，1366x768 可用

### 4.3 数据
- MVP 阶段使用 Mock 数据
- 后续对接 EDC API

### 4.4 多语言支持
- 需支持多语言显示的接口设计
- 默认中文（zh-CN），预留英文（en-US）、繁体中文（zh-TW）、日语（ja-JP）占位
- UI 文案需可配置、可替换

## 5. 约束条件

- 不添加 TECH_STACK.md 之外的依赖
- 遵循 UI 原型设计
- 模块间解耦，支持独立部署
